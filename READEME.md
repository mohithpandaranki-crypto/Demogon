# Demogon

Demogon is a small learning dashboard I am building to make my daily learning more organized. The idea is to keep the topics I study in one place and gradually add features that help me understand what I know and what I need to revise.

I started this project to practise HTML, CSS and JavaScript by building something of my own.

## What it includes

- A learning dashboard with an overview of topics and progress.
- A form for entering a topic, its subject and a confidence rating.
- A section for reviewing topics using questions and answers.
- A progress page to show learning progress.
- A simple interface with white and light-green colours.

**Project status:** This project is still under development. The dashboard layout and topic form are in place, and I am working on connecting the different sections to make the features fully functional.

## Built with

- HTML
- CSS
- JavaScript

## How to run it

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `Htmlcode.html` in your browser, or use the Live Server extension in VS Code.

No additional packages are required for the current front-end setup.

## Project files

- `Htmlcode.html` — page structure
- `csscode.css` — styling and layout
- `jscode.js` — JavaScript functionality
